# PRODIGY_SD_02

## Number Guessing Game

This project is part of **Prodigy InfoTech Internship – Task 2**.

### Description
This program generates a random number and challenges the user to guess it.
It provides feedback if the guess is too high or too low and continues until
the correct number is guessed. The program also displays the number of attempts.

### Technologies Used
- Python 3
- Visual Studio Code

### How to Run
```bash
python task2.py
